Find and connect a text model

A curated directory checked on November 26, 2026—not every API on the internet. Free offers, models, regions and account eligibility can change. Official links describe the current terms. Consumer chat subscriptions do not automatically include API access.

Guides and presets do not prove live availability. Saving never sends a model request. Test only after checking the provider's plan and data policies.

Commonly listed, but not currently free

GitHub Models: retired. Hugging Face: no included inference credits for free accounts. SambaNova: current plan requires purchased credits. Other providers and regional offers may exist; this directory is not exhaustive.

  1. Open the provider's official account page and review its eligibility, limits and data policy.
  2. Create your own API key (or start your local model server). Never use shared keys found online.
  3. Review the prefilled connection below. Enter an available text model ID and your key.
  4. Save, then optionally test. Finally select the connection in chat.

Credentials are stored encrypted by your local backend. No key is stored in browser storage. Rates remain unknown until you configure them. This creates a new connection and does not change your default or fallback order.

Test this connection?

A short greeting will be sent to the selected provider. It can consume credits or quota and appears in Usage. Saving a connection is not a guarantee of free usage.
