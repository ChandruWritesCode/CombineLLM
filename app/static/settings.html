APIs and account logins

Gemini, OpenAI, and Claude use API credentials. OpenAI-compatible endpoints can connect services such as Grok, Perplexity, or a private gateway when they support the Chat Completions protocol.

OpenRouter supports browser sign-in: save an OpenRouter model, then choose Connect account. Your password stays with OpenRouter. An account connection does not make inference free. ChatGPT or Claude website subscriptions are not generic API credentials.

For Ollama on your machine, use http://localhost:11434/v1 for native development or http://host.docker.internal:11434/v1 from Docker. The model must already be installed and the service reachable.

Credentials are encrypted on disk. Back up the database and its matching .key file. The key lives beside the database, so encryption does not protect against someone with access to your whole machine. Keep this app bound to localhost.
